# alias-file
This is the alias file format with a .alias file extension where you can create alias files and run then using the alias manager program wheter to create a new alias or to open one already created

.alias File Format Specification1. OverviewThe .alias file format is a lightweight binary container specification designed to store direct reference paths to local file targets. The format consists of a fixed-size header section followed by a variable-length payload section containing the hexadecimal-encoded file path.2. Binary Layout SpecificationAll .alias files strictly adhere to a 5-byte fixed header followed immediately by the file path payload. 0x00       0x01       0x03       0x05                                0x05 + N
+----------+----------+----------+------------------------------------+
|   Type   | Version  |   Size   |            Hex Payload             |
| (1 Byte) | (2 Bytes)| (2 Bytes)|             (N Bytes)              |
+----------+----------+----------+------------------------------------+

Format Rules & Data StandardsStrict Big-Endian Encoding: All multi-byte and single-byte fields within the header structure (Type, Version, and Size) are explicitly stored using Big-Endian byte ordering.Hexadecimal String Payload: The target file path is stored exclusively as an ASCII string composed of hexadecimal representations of the underlying path characters.Payload Boundaries: The Size field defines the exact number of bytes $N$ that follow the 5-byte header. The maximum allowable payload size for version 1.0 is $65,535$ bytes (0xFFFF).Encoding Integrity: The payload must represent valid hex pairs corresponding to an absolute target path string.
